# Installation

Install 4Mica packages for each supported language. This root-level page is kept for existing links; the organized navigation points to the newer sectioned docs where applicable.

## Key Points

- TypeScript: `pnpm install @4mica/sdk@alpha` — deposit, pay for 402-protected requests, and withdraw with `FourMica`. See the [Quickstart](/getting-started/quickstart).
- TypeScript, existing x402 clients and seller middleware: `pnpm install @4mica/x402@alpha @x402/fetch @x402/axios viem`
- Python: `pip install "4mica-x402[fastapi]" "4mica-x402[requests]" sdk-4mica`
- Rust: `cargo add sdk-4mica alloy`

The TypeScript SDK reads `FOURMICA_*` environment variables, such as `FOURMICA_WALLET_PRIVATE_KEY` and `FOURMICA_NETWORK`; see [Configuration](/sdks/typescript/configuration).

## 4Mica Context

4Mica is the clearing house for the agentic economy: a credit layer for x402 that lets agents and applications transact instantly, earn yield on collateral, and settle net positions later.
