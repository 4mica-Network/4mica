4Mica uses <Tooltip headline="CAIP-2" tip="Chain Agnostic Improvement Proposal 2: a standard format for identifying blockchain networks, such as eip155:8453 for Base.">CAIP-2</Tooltip> network IDs so buyers, sellers, SDKs, and facilitator calls all refer to the same chain.

Use the network ID in payment requirements, SDK configuration, and scheme registration. Use the API URL when your server talks to the 4Mica facilitator for that network.

## Values

```txt
Base Sepolia
Network ID: eip155:84532
Core API URL: https://base.sepolia.api.4mica.xyz/
Facilitator URL: https://x402.4mica.xyz/
Accepted collateral: USDC 0xba50Cd2A20f6DA35D788639E581bca8d0B5d4D5f, USDT 0x0a215D8ba66387DCA84B284D18c3B4ec3de6E54a (Aave test tokens)
Use for: Development, examples, demos, integration testing, and pilots

Base
Network ID: eip155:8453
Core API URL: https://base.api.4mica.xyz/
Use for: Production traffic on the previous protocol version; the 2.0 upgrade is pending

Ethereum Sepolia
Network ID: eip155:11155111
Core API URL: https://ethereum.sepolia.api.4mica.xyz/
Use for: Legacy, x402 v1 only
```

The Base Sepolia tokens are Aave's testnet tokens, minted through Aave's public faucet contract
rather than a Circle faucet; see the [quickstart](/getting-started/quickstart) for the one-line mint.
Ask core which tokens it accepts on any network with
[`GET /core/tokens`](/api-reference/operator/tokens).

## Choosing a network

- Start with **Base Sepolia**. It is the network the SDKs default to and the one the 2.0 protocol
  runs on today.
- **Base** still runs the previous protocol version. SDK 2.0 clients cannot pay there until the
  mainnet upgrade lands; this page will change when it does.
- **Ethereum Sepolia** is kept for legacy integrations and serves x402 v1 only.
