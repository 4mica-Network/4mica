# Configuration

`@4mica/sdk` needs a signer and uses sensible defaults for everything else. Pass options to `FourMica.connect`, or let it read `FOURMICA_*` environment variables.

## `FourMica.connect` options

| Option           | Default                                  | Description                                                                 |
| ---------------- | ---------------------------------------- | --------------------------------------------------------------------------- |
| `privateKey`     | —                                        | Hex private key. Mutually exclusive with `signer`.                          |
| `signer`         | —                                        | A viem `Account` with `signTypedData` and `signMessage` (CDP, Privy, Turnkey, KMS). |
| `network`        | `base-sepolia`                           | Network shorthand or CAIP-2 id. When reading the environment, `FOURMICA_NETWORK` comes first. |
| `facilitatorUrl` | The network's hosted facilitator         | Facilitator that sponsors gas. Without one, deposits are the wallet's own transactions. |
| `rpcUrl`         | The network's hosted core                | Core API URL of a self-hosted deployment. Replaces `network`.              |
| `spend`          | `{ perPayment: "1 USDC" }`               | Limits on what `client.fetch` pays: `perPayment`, `total`, `payTo`. See [spend limits](/buyer/make-paid-requests-automatically#spend-limits). |
| `env`            | `process.env`, where the runtime has one | Where to read `FOURMICA_*` variables when neither `privateKey` nor `signer` is given. |
| `protocols`      | `["x402"]`                               | Payment protocols `client.fetch` may use, in order of preference.           |
| `fetch`          | The global `fetch`                       | `fetch` implementation for HTTP calls to sellers.                           |

```ts
import { FourMica } from "@4mica/sdk";

await using client = await FourMica.connect({
  privateKey: process.env.PRIVATE_KEY,
  network: "base-sepolia",
  spend: { perPayment: "0.50 USDC", total: "20 USDC" },
});
```

`connect` throws a `ConfigError` when no signer is given, when both `privateKey` and `signer` are, or when a network or URL is invalid. A malformed `spend` amount also fails here, not on the first payment.

Pass `network` explicitly in code that moves real money. The default is Base Sepolia today and will change when the mainnet upgrade lands.

## Using environment variables

With neither `privateKey` nor `signer`, `FourMica.connect()` reads its configuration from the environment.

```bash
export FOURMICA_WALLET_PRIVATE_KEY="0x..."
export FOURMICA_NETWORK="base-sepolia"   # shorthand or CAIP-2 id
# or point at a self-hosted core instead:
# export FOURMICA_RPC_URL="https://core.example.com/"
export FOURMICA_FACILITATOR_URL="https://testnet.payment.4mica.io/"
export FOURMICA_ETHEREUM_HTTP_RPC_URL="http://localhost:8545"
export FOURMICA_CONTRACT_ADDRESS="0x..."
export FOURMICA_BEARER_TOKEN="Bearer <access_token>"
export FOURMICA_AUTH_URL="https://base.sepolia.api.4mica.io/"
export FOURMICA_AUTH_REFRESH_MARGIN_SECS="60"
```

```ts
import { FourMica } from "@4mica/sdk";

await using client = await FourMica.connect({ network: "base-sepolia" });
```

Options you pass still win: here `network` overrides `FOURMICA_NETWORK`. `FOURMICA_NETWORK` takes precedence over `FOURMICA_RPC_URL`. When you pass `privateKey` or `signer`, the environment is not read at all.

<Note>
  The older `4MICA_*` names still work. Setting both names of one variable to
  different values is a `ConfigError`. Prefer `FOURMICA_*`: a shell cannot
  `export` a name that starts with a digit.
</Note>

On runtimes without `process.env`, pass the environment yourself, for example `FourMica.connect({ env: Deno.env.toObject() })`.

## Using a custom signer

To integrate a hardware wallet, remote signer, or MPC wallet, pass a viem `Account` as `signer`. It must expose `address`, `signTypedData`, and `signMessage`.

### Coinbase CDP wallet

Use `createCdpAccount` for a Coinbase CDP MPC wallet whose private key never leaves CDP. It returns a viem `Account`. This requires the optional `@coinbase/cdp-sdk` dependency.

```ts
import { createCdpAccount, FourMica } from "@4mica/sdk";

const signer = await createCdpAccount({
  apiKeyId: process.env.CDP_API_KEY_ID!,
  apiKeySecret: process.env.CDP_API_KEY_SECRET!,
  walletSecret: process.env.CDP_WALLET_SECRET!,
  name: "my-agent-wallet", // idempotent — the same name returns the same wallet
});

await using client = await FourMica.connect({ signer, network: "base-sepolia" });
```

## Advanced: exact control

`FourMica` is a facade over `Client`. For anything it does not cover, `await client.lowLevel()` returns the session's `Client`, already configured. To build a `Client` yourself, build a `Config` with `ConfigBuilder` and pass it to `Client.connect`.

| Option                 | Required                         | Description                                                             |
| ---------------------- | -------------------------------- | ----------------------------------------------------------------------- |
| `walletPrivateKey`     | Yes, unless `signer` is provided | Private key used for signing.                                           |
| `signer`               | Yes, unless `walletPrivateKey`   | A pre-built viem `Account`. Mutually exclusive with `walletPrivateKey`. |
| `network`              | No                               | Network shorthand or CAIP-2 id. Defaults to `base-sepolia`. Also selects the network's hosted facilitator. |
| `rpcUrl`               | No                               | Override the core API URL directly (for self-hosted deployments).       |
| `ethereumHttpRpcUrl`   | No                               | Ethereum JSON-RPC endpoint. Fetched from core when omitted.             |
| `contractAddress`      | No                               | Treasury contract address. Fetched from core when omitted.              |
| `facilitatorUrl`       | No                               | Facilitator that sponsors gas. Without one, every operation is self-funded. |
| `bearerToken`          | No                               | Static bearer token for auth. Replaces SIWE auth.                       |
| `authUrl`              | No                               | SIWE auth endpoint. Defaults to `rpcUrl` when auth is enabled.          |
| `authRefreshMarginSecs`| No                               | Seconds before expiry at which the session refreshes. Defaults to 60.   |

<Note>
  `ethereumHttpRpcUrl` and `contractAddress` are fetched from the core service by
  default. The SDK validates the connected chain id but does not verify the
  contract address or code. Only override these if you need values that differ
  from the server defaults.
</Note>

```ts
import { Client, ConfigBuilder } from "@4mica/sdk";

const cfg = new ConfigBuilder()
  .network("base-sepolia")
  .walletPrivateKey(process.env.PRIVATE_KEY!)
  .build(); // or new ConfigBuilder().fromEnv().build() to read FOURMICA_*

const client = await Client.connect(cfg);
try {
  await client.login(); // optional: pre-warm the SIWE session
} finally {
  await client.aclose();
}
```

`build()` throws a `ConfigError` when a signer or wallet key is missing, a URL is invalid, or the auth refresh margin is not a finite non-negative number. A `Client` you build yourself is not closed by `await using`; call `aclose()`.

### SIWE authentication

Auth is enabled by default, and the first authenticated RPC call logs in automatically. Connecting never triggers a login — the bootstrap routes are public. Use a static token instead of SIWE, or turn credentials off entirely:

```ts
const cfg = new ConfigBuilder()
  .walletPrivateKey("0x...")
  .bearerToken("Bearer <access_token>")
  .build();

const anonymous = new ConfigBuilder()
  .walletPrivateKey("0x...")
  .disableAuth()
  .build();
```

<Warning>
  Never commit private keys. Use a test wallet while you develop and a dedicated
  service wallet, hardware-backed signer, MPC wallet, or hosted key management
  system in production.
</Warning>

<Tip>
  Start on Base Sepolia (`eip155:84532`) with small amounts. Once a flow works end
  to end, move shared values into environment variables and switch networks.
</Tip>
