# TypeScript SDK

`@4mica/sdk` is the official TypeScript SDK for the 4Mica payment network. Use it to deposit collateral, pay for HTTP 402-protected resources, withdraw, sign and settle guarantees, and gate your own routes behind a payment.

It has two layers:

- **`FourMica`** — connect once, then deposit, pay, and withdraw with amounts written as `"5 USDC"`. Start here.
- **`Client`** — the exact-control layer: intent builders for every deposit, withdrawal, guarantee, and settlement route, with amounts in base units. Reach it from a session with `await client.lowLevel()`.

## Runtime-neutral

`@4mica/sdk` runs on Node, Bun, Deno, and edge runtimes. HTTP uses the global `fetch`, and payment headers are encoded without `Buffer`, so it runs on the edge.

## Install

Node.js 18 or later is required.

<CodeGroup>

```bash npm
npm install @4mica/sdk
```

```bash pnpm
pnpm install @4mica/sdk
```

```bash yarn
yarn add @4mica/sdk
```

```bash bun
bun add @4mica/sdk
```

</CodeGroup>

## Your first session

Connect, deposit, and make a paid request. Start on Base Sepolia with a test wallet.

```ts
import { FourMica } from "@4mica/sdk";

await using client = await FourMica.connect({
  privateKey: process.env.PRIVATE_KEY,
  network: "base-sepolia",
});

await client.deposit("5 USDC");
const response = await client.fetch("https://api.example.com/data");
```

`FourMica.connect` reaches the core service for its public parameters and checks that it supports the guarantee version this SDK signs. `await using` closes the session when `client` goes out of scope, even if a call throws.

<Note>
  `await using` needs TypeScript 5.2 or later. Plain JavaScript needs a runtime
  with native `await using` (Node 24 or later); otherwise call
  `await client.close()` in a `finally` block. If TypeScript reports that
  `Symbol.asyncDispose` is missing, add `"esnext.disposable"` to `lib` in
  `tsconfig.json`.
</Note>

| Call | What it does |
| --- | --- |
| `client.deposit("5 USDC", options?)` | Deposits collateral, gasless where the network's facilitator can sponsor it. Resolves once core counts it. |
| `client.balance()` / `client.balance("USDC")` | Collateral per asset: `total`, `locked`, and `available` as decimal strings, plus `raw` bigints. |
| `client.fetch(input, init?)` | The global `fetch` signature. Pays a 4Mica 402 within the session's spend limits and retries once. |
| `client.paymentFor(response)` | What `fetch` paid for a response, or `undefined`. |
| `client.withdraw("2 USDC")` | Requests a withdrawal. The grace period starts now. |
| `client.withdrawals()` | Pending withdrawal requests, each with `readyAt`. |
| `client.finalizeWithdrawal("USDC")` | Pays out a requested withdrawal once its grace period has ended. |
| `client.cancelWithdrawal("USDC")` | Cancels a requested withdrawal. |
| `await client.lowLevel(network?)` | The underlying `Client`, for anything the facade does not cover. |
| `client.close()` | Closes the session. `await using` calls it for you. |
| `client.address` / `client.network` | The signer address, and the session's network. |

`deposit`, `balance`, and the withdrawal calls take an optional `{ network }` to use another network; the session connects it on first use.

### Amounts

Amounts are decimal strings with their asset: `"5 USDC"` or `{ amount: "5", asset: "USDC" }`. The asset is a symbol core lists (any case), `"ETH"` for the native asset, or a token address. Numbers and bigints are rejected on purpose, since `5` could mean 5 USDC or 5 base units. An amount with more decimals than the token has throws `AmountPrecisionError`; the SDK never rounds.

## Networks

The default network is Base Sepolia (`DEFAULT_NETWORK`). Select another with the `network` option of `FourMica.connect` or the `FOURMICA_NETWORK` environment variable. Base still runs the previous protocol version, so 2.0 clients cannot pay there yet; see [supported networks](/getting-started/supported-networks).

| Shorthand          | CAIP-2            | Core API URL                              |
| ------------------ | ----------------- | ----------------------------------------- |
| `base`             | `eip155:8453`     | `https://base.api.4mica.io/`             |
| `base-sepolia`     | `eip155:84532`    | `https://base.sepolia.api.4mica.io/`     |
| `ethereum-sepolia` | `eip155:11155111` | `https://ethereum.sepolia.api.4mica.io/` (legacy, x402 v1 only) |

Read network details from the exported `NETWORKS` constant:

```ts
import { NETWORKS } from "@4mica/sdk";

console.log(NETWORKS["base-sepolia"].caip2); // "eip155:84532"
console.log(NETWORKS["base-sepolia"].facilitatorUrl); // "https://testnet.payment.4mica.io/"
```

## Exact control with `Client`

`await client.lowLevel()` returns the session's `Client`, which the session closes for you. Its capability sub-clients take amounts in base units:

- **`deposit`** — deposit collateral in ETH or ERC20 tokens, choosing the route.
- **`withdraw`** — request, cancel, and finalize withdrawals.
- **`payment`** — sign, issue, and verify payment guarantees.
- **`settlement`** — settle a cleared cycle from either side: the debtor pays, the creditor claims.
- **`account`** / **`tokens`** — the signer's balances and supported-token metadata.

Alongside it, `X402Flow` turns a `402 Payment Required` response into a signed payment header, and `@4mica/sdk/server` is an edge-safe paywall that gates a route behind an x402 payment.

To build a `Client` yourself, use `ConfigBuilder` and `Client.connect`; see [Configuration](/sdks/typescript/configuration#advanced-exact-control).

<Warning>
  Keep private keys in environment variables instead of committing them to your
  code. Use a dedicated test wallet while you develop.
</Warning>
